4. Gaps found by this audit (nobody had these)

Gap 1. The data-complete flag is wrong on any fresh import

collector/store_write.py takes the cut-off from the store's newest period BEFORE the batch lands. On a first import the store is empty, so every row compares against itself and is marked incomplete, whatever its age.

Reproduced in a temp database: five weekly rows from Jan 2024 to Aug 2026 all came back data_complete = 0. In the dev store, 813 of 913 high-volume campaign-weekly rows are flagged incomplete back to Sept 2024, and 108 of 144 low-volume monthly rows.

The test passes only because it seeds a row first. Nothing consumes data_complete or restated yet, so no finding is affected today, but the board's "tested both directions" is an intent-time claim.

Gap 2. Most open findings have no window or volume footer

Doc 01: "No number appears without its window and volume." The board claims a footer on every displayed row. Of 64 open findings, 45 have no window start and 36 have no click or conversion volume. format_ads.py silently omits the footer when the values are NULL. Worst rules: K7 (10), G2 (7), W2 (5), K1 (5).

Gap 3. Persistence constants still override real history

Falsification item 7 ("constants impersonate a history") is marked closed. The engine now counts a real observation streak, but takes the maximum of that and the evaluator's own constant, and rules_impl.py still hard-codes periods_outside_normal = 3 or 6 in about twelve places.

Effect in data: 0 "watch" rows among 1,573 observations (9 advisory, 1,564 alert). The gate-5 watch tier is never reached, so "watch never publishes" is true only because nothing is ever watch.

Gap 4. One pound-sign sibling left in the engine

engine/engine.py line 903 hard-codes a pound sign in the snooze-expiry note ("spent on this entity while suppressed"). Unreached on the mockups, but a USD account whose suppression expires would print pounds. chart.html and svchart.html also hard-code pounds.

Gap 5. Stale prose in the human-facing docs

COMPLIANCE.md says "13 suites" (it is 14) and still lists constraints auto-suppression, rule-quality rates and restatement as "need real usage" although they were built on 1 Sept. FALSIFICATION-31AUG.md's "still open" tail says 23 evaluator-less rules (now 1). REPAIR-STATUS.md's "honestly open" section repeats the pre-sweep list. TESTING.md is the 18 Aug pre-build note pointing at v1's battery, and README still cites it. format_ads.py still comments "plain pounds".
