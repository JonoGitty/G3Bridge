The premise

An old Mac is a lovely object and a terrible internet client. It has no security patches, a TLS stack no modern site will accept, and a browser from 2008.

So the machines get no route at all — no gateway, no DNS. They can address exactly one thing: the PC on the other end of the cable. The PC has the internet, the CPU and the disk, and acts as their eyes and hands.

That constraint turns out to be the interesting part. Once a modern machine is allowed to do the fetching, decoding and rendering, a great deal of the present-day web becomes usable again on hardware two decades past its service life.

How it fits together

A long-lived daemon owns the cable. Everything else talks to it.

The daemon is deliberately long-lived: the MCP server is a short-lived child process and must not be the thing holding the connection open.

It runs on Windows Python, not WSL. WSL2 sits behind NAT, so a device on the far end of the cable simply cannot reach a listener inside it. That single fact shaped the whole host architecture, and it was worth an hour of checking rather than an afternoon of debugging.

What the old machines get

A small site, written for Safari 3: CSS2 only, no flexbox, ES3-era JavaScript, and nothing loaded from anywhere but the PC.

PageWhat it does
/newsEight RSS feeds, fetched by the PC on a background thread so a page load never waits on the network. A feed that fails keeps serving its last good copy.
/gamesSnake, Breakout, Tetris and Asteroids. Canvas, keyboard, no plugins. Each was written and then adversarially reviewed for syntax a 2008 browser cannot parse.

The codec decision

Everyone reaches for H.264. On a 1.25 GHz G4 it is decodable but expensive. MPEG-4 Part 2 is what QuickTime on PowerPC was actually built around and costs a fraction of the CPU, so it is the default at 480×360. A ten-minute 1080p source converts in 63 seconds and streams at about 816 kbps — trivial over 100 Mbit.

Why sanitising is a feature, not a limitation

A 2026 website will not render in Safari 3 in any case. Reduced to headings, paragraphs, tables and links, most of the web becomes readable again. Wikipedia arrives as 100 KB of clean HTML from 292 KB raw, with 825 links proxied. Nothing executable reaches the machine, and it still opens no connection to anyone but the PC.

Isolation, verified rather than asserted

The requirement was a guarantee, so the project checks it instead of claiming it — from both ends.

From the Mac

ping 8.8.8.8 returns 100% packet loss. apple.com does not resolve. There is no default gateway and no name server configured, so it cannot address anything off its own subnet.

From the PC — six controls, checked read-only

!!WSL2’s second IP stackforwarding, both networks

The sixth check exists because the first five were not enough. An early version of this report would have said “all controls pass”. They did — and the claim was still incomplete.

WSL2 runs its own Linux TCP/IP stack in mirrored networking mode, with one interface on the cable subnet and another on the internet carrying a default route, and ip_forward=1. It is a second router straddling both networks, and no Windows-side query can see it. The Mac having no gateway means nothing was ever actually leaking — but a guarantee with an invisible gap in it is not a guarantee.

The listeners bind the cable adapter specifically rather than all interfaces, and every inbound connection — agent socket and HTTP alike — is matched against the configured machines by address and refused if unknown. Attempting to fetch from the PC’s own cable address correctly returns 403.

Ten bugs, and what each one taught

Every one of these was found by running the thing, not by reading it. That is the argument for building simulators early.

Two threads reading one socket

The pump stole replies out from under the sender, so every command after the first failed with a misleading “connection closed”.

One reader, waking per-sequence waiters. Two readers on a socket silently eat each other.

Python 3 cannot syntax-check Python 2.3

Python 3.14 parses except Exception, e as a tuple of exception classes and accepts it silently — passing the code while meaning something entirely different.

A purpose-built lint for the vintage dialect. A modern parser is not a validator for an old one.

Pillow dithers by default

Flat vector artwork encoded to 135 KB instead of 15 KB. A browser reloading that every two seconds exhausted the classic Mac’s fixed memory partition and crashed the machine.

Dithering off. An 8× reduction, and the crash was self-inflicted rather than the hardware failing.

Frame URLs were uncacheable

The Mac re-downloaded an unchanged image every cycle.

The counter only advances when the picture changes, so each URL is immutable and cacheable. Steady state fell from 135 KB to 373 bytes.

Void tags in the sanitiser’s drop set

Tags like <link> emit no closing tag, so the drop counter incremented forever and swallowed the document. Wikipedia came back as a two-byte page.

Void tags no longer touch the counter. The same fetch is now 100 KB of readable HTML.

Chunks decoded before joining

A chunk boundary landing inside a percent-escape ate a character — one line vanished from a 59-line listing, silently.

Join raw, decode once. The simulator now splits badly on purpose so this stays covered.

Enumerating addresses instead of probing

getaddrinfo never returned the adapter’s manual addresses, so binding fell through to all interfaces and the “cable adapter only” guarantee was silently false.

Ask the OS by attempting the bind. Don’t infer a capability you can test directly.

An empty quoted string was dropped

The far end would have received a command with a missing argument and thrown — on a machine with no debugger.

Caught by a round-trip test between the encoder and the hand-written parser at the other end.

Stale status fields

Reported a machine’s screen size while also reporting it as disconnected — which reads as a live machine.

Report details only while attached.

Two keys named os

Config said macosx, the machine reported 10.5.6. Anything parsing the line into a dictionary took whichever came last.

Namespace what the machine tells you separately from what you assumed.

What isn’t proven

The least interesting report is one that only lists successes.

  • The Mac OS 9 agent has never run. It is written against verified Carbon API shapes and lints clean for Python 2.3, but no line of it has executed on the actual machine.
  • Nothing has been seen on a real CRT. Every page is written for Safari 3 and verified by fetching it — never by looking at it on the glass.
  • Video smoothness on the G4 is untested. The encode profile is reasoned from what that generation of QuickTime was built for, not measured.
  • The eMac’s hardening is written but unapplied — it needs an admin password. Two gaps stand: a subnet mask a byte too wide, and IPv6 left on automatic. Neither is an active hole.
  • The G3’s fault is not confidently diagnosed. An earlier version of this analysis said “thermal capacitors, near certain”. That was overconfident: a stuck-but-alive machine is at least as likely, no-chime is weak evidence because chime volume lives in PRAM, and RAM faults on that model are audible.

Built in a single session on 1 September 2026. Twenty-four commits, four test suites, two simulators so the host could be developed with nothing plugged in. The most useful hour was spent checking assumptions about hardware nobody has documented properly in twenty years.
